الدليل الشامل لتشغيل نماذج الذكاء الاصطناعي محلياً على جهازك

مقدمة عن Ollama

Ollama هي أداة مفتوحة المصدر تتيح لك تشغيل نماذج الذكاء الاصطناعي اللغوية الكبيرة (LLMs) محلياً على جهازك دون الحاجة للاتصال بالإنترنت. يمكنك استخدامها للبرمجة، الكتابة الإبداعية، الترجمة، المساعدة الشخصية وأكثر.

ملاحظة: تعمل Ollama بشكل أفضل على أجهزة ذات مواصفات جيدة، لكن يمكن تشغيلها على أجهزة متوسطة مثل i5 من الجيل الثالث باستخدام النماذج الخفيفة.

متطلبات النظام

  • نظام التشغيل: Windows 10/11، macOS، أو Linux
  • المعالج: Intel/AMD CPU (يعمل على i5 الجيل الثالث ولكن بأداء محدود)
  • الذاكرة (RAM): 8GB على الأقل، 16GB مفضل
  • مساحة التخزين: 10GB على الأقل للنماذج الصغيرة

تثبيت Ollama على Windows

  1. قم بتحميل المثبت من الموقع الرسمي: https://ollama.com/download/windows
  2. قم بتشغيل الملف الذي تم تحميله
  3. اتبع خطوات التثبيت البسيطة
  4. انتظر حتى يكتمل التثبيت وسيبدأ Ollama في العمل تلقائياً في الخلفية
ملاحظة: يجب أن تكون قد قمت بتمكين ميزة WSL (Windows Subsystem for Linux) أولاً.

تثبيت Ollama على Linux

استخدم الأمر التالي لتثبيت Ollama:

curl -fsSL https://ollama.com/install.sh | sh

بعد الانتهاء من التثبيت، يمكنك التحقق من أن Ollama يعمل بشكل صحيح عن طريق:

ollama --version

تثبيت واجهة المستخدم الرسومية (Open WebUI)

Ollama لا تأتي مع واجهة مستخدم رسومية، لذلك سنقوم بتثبيت Open WebUI، وهي واجهة مجانية ومفتوحة المصدر.

طريقة Docker
التثبيت اليدوي

تثبيت Open WebUI باستخدام Docker

  1. تأكد من تثبيت Docker على جهازك أولاً
  2. قم بتشغيل الأمر التالي لتثبيت وتشغيل Open WebUI:
docker run -d --name open-webui -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data ghcr.io/open-webui/open-webui:main

بعد الانتهاء من التثبيت، افتح المتصفح وانتقل إلى:

http://localhost:3000

التثبيت اليدوي لـ Open WebUI

متطلبات مسبقة:

  • تثبيت Node.js
  • تثبيت Git

خطوات التثبيت:

git clone https://github.com/open-webui/open-webui.git
cd open-webui
npm install
npm run dev

بعد الانتهاء، افتح المتصفح وانتقل إلى:

http://localhost:3000

الإعداد الأولي للواجهة

إعداد Open WebUI

  1. قم بإنشاء حساب جديد عند فتح واجهة Open WebUI لأول مرة
  2. انتقل إلى صفحة الإعدادات (Settings)
  3. تأكد من إضافة عنوان Ollama API: http://localhost:11434
  4. احفظ الإعدادات

تحميل وتشغيل النماذج

الآن بعد تثبيت Ollama والواجهة، يمكنك تحميل وتشغيل نماذج الذكاء الاصطناعي.

تحميل النموذج من واجهة Open WebUI

  1. انتقل إلى قسم "Models" من القائمة الجانبية
  2. ابحث عن النموذج المناسب لجهازك
  3. انقر على زر "Pull" لتحميل النموذج
  4. انتظر حتى يكتمل التحميل

تحميل النموذج من سطر الأوامر

يمكنك أيضًا تحميل النماذج باستخدام سطر الأوامر:

ollama pull phi

لتشغيل النموذج بعد التحميل:

ollama run phi

النماذج المناسبة للأجهزة الضعيفة (i5 الجيل الثالث)

Phi-2 (2.7GB)

الوصف: نموذج خفيف جدًا مع أداء ممتاز في البرمجة، مثالي للأجهزة الضعيفة

أمر التثبيت:

ollama pull phi

TinyLlama (1.1GB)

الوصف: أصغر نموذج، سريع جدًا ويستهلك موارد قليلة

أمر التثبيت:

ollama pull tinyllama

CodeLlama-7B (7GB)

الوصف: متخصص في البرمجة وكتابة الأكواد

أمر التثبيت:

ollama pull codellama:7b

Mistral-7B (7GB)

الوصف: متوازن للمهام العامة والبرمجة

أمر التثبيت:

ollama pull mistral

نصائح لتحسين الأداء

  1. قلل قيمة سياق المحادثة (Context Length): استخدم --num_ctx 1024 لتحسين الأداء
  2. أغلق البرامج الأخرى: تأكد من عدم تشغيل برامج تستهلك موارد كثيرة أثناء استخدام Ollama
  3. استخدم النماذج الصغيرة: اختر النماذج بحجم 7B أو أقل للأجهزة الضعيفة
  4. استخدم ملف Modelfile لضبط الإعدادات:

مثال على ملف Modelfile:

FROM phi
SYSTEM "أنت مساعد برمجة متخصص في تعريب الألعاب، تقدم المساعدة باللغة العربية"
PARAMETER temperature 0.7
PARAMETER num_ctx 1024

لإنشاء نموذج مخصص باستخدام الملف:

ollama create game-translator -f game-translator.modelfile
ollama run game-translator

استكشاف الأخطاء وإصلاحها

مشكلة: Ollama لا تعمل

الحل: تأكد من تشغيل خدمة Ollama في الخلفية:

# على Windows (في PowerShell بصلاحيات المسؤول)
Start-Service ollama

# على Linux/macOS
sudo systemctl start ollama    # إذا كنت تستخدم systemd
sudo service ollama start      # إذا كنت تستخدم initd

مشكلة: الواجهة لا تتصل بـ Ollama

الحل: تأكد من أن عنوان API صحيح في الإعدادات (http://localhost:11434)

مشكلة: النموذج بطيء جدًا

الحل:

  • استخدم نموذج أصغر (مثل Phi-2 أو TinyLlama)
  • قلل قيمة سياق المحادثة (--num_ctx 1024 أو أقل)
  • قلل قيمة عينات التنبؤ (--num_predict 512)

تم إنشاء هذا الدليل لمساعدة المبرمجين ومعربي الألعاب على استخدام نماذج الذكاء الاصطناعي محلياً.
